FRESHEN MUSIC RADIO 0.3

В этой версии добавлено управление облачными плейлистами:
- создание и удаление плейлистов;
- добавление треков из медиатеки;
- удаление треков из плейлиста;
- изменение порядка кнопками вверх/вниз;
- воспроизведение плейлиста с переходом к следующей песне.

Перед заменой файлов проверь сайт на локальной копии, если хочешь.
Для публикации замени index.html, app.js и styles.css в GitHub.
Supabase URL и Publishable key уже находятся в app.js.
