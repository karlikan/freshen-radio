# FRESHEN MUSIC RADIO

Веб-интерфейс собственной интернет-радиостанции.

## Текущий этап: 0.1.0 — интерфейс-прототип

Реализованы внешний вид Control Room, локальное добавление аудиофайлов, очередь и предпрослушивание в браузере.

Это пока **не публичное интернет-радио**: файлы существуют только в памяти открытой вкладки, а воспроизведение прекращается при ее закрытии. Серверный AutoDJ, постоянный Icecast-поток и Live Studio еще не подключены.

## Важно

Не добавляйте секретные ключи, пароли или токены в публичный репозиторий. Цель проекта — найти инфраструктуру, которая действительно работает бесплатно и без банковской карты. Наличие такого хостинга для круглосуточного аудиопотока пока не подтверждено.
