# FRESHEN MUSIC RADIO 0.2

Облачная музыкальная медиатека на Supabase и сайт на Vercel.

## Возможности
- Вход администратора через Supabase Auth.
- Загрузка MP3, WAV, FLAC и M4A.
- Сохранение названия, исполнителя и длительности.
- Просмотр, поиск, предпрослушивание и удаление треков.
- Публичное чтение библиотеки, административные операции защищены RLS.

## Важно
Это пока не полноценная круглосуточная радиостанция. В этой версии есть облачная библиотека и браузерный проигрыватель. Здесь еще нет AutoDJ 24/7, live DJ с микрофоном, Icecast и прямого URL потока для Euro Truck Simulator 2.

## Настройки Supabase
В app.js уже указаны URL проекта и Publishable key. В браузере допустимо использовать только Publishable key или anon key. Никогда не вставляйте service_role или secret key.

Нужны:
- таблица public.tracks со столбцами id, title, artist, file_path, duration, created_at;
- Storage bucket с именем tracks;
- bucket должен быть Public, чтобы проигрыватель мог получать аудио через getPublicUrl;
- RLS policies для чтения треков и административных операций.

## Публикация
1. Распакуйте ZIP.
2. Откройте https://github.com/karlikan/freshen-radio
3. Замените в корне репозитория index.html, styles.css, app.js и README.md.
4. Нажмите Add file → Upload files.
5. Загрузите четыре файла и нажмите Commit changes в ветку main.
6. Vercel автоматически запустит новый Production Deployment.
7. Откройте https://freshen-radio.vercel.app/ и обновите страницу через Ctrl+F5.

## Проверка
1. Вверху сайта должно появиться SUPABASE ONLINE.
2. Нажмите Войти и используйте email и пароль пользователя Supabase Auth.
3. После входа появится панель Добавить музыку.
4. Загрузите небольшой MP3 для проверки.
5. Проверьте, что трек появился и воспроизводится.

## Ограничение
Интерфейс ограничивает файл 50 МБ. Это клиентская проверка, а фактический лимит зависит от настроек Supabase и тарифа.
